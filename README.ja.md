# HinanMemo

HinanMemoは、災害時に現在地周辺の避難施設情報を確認できるiOSアプリです。

## 機能
- CoreDataとCoreLocationを使用し、現在地周辺の避難施設データを取得・保存
- 周辺施設のリスト表示および、地図アプリでの位置情報の表示
- 保存したデータのクリア機能

## 要件
- iOS 9以降
- Swift 2.2

## 使い方
1. リポジトリをクローンし、Xcodeプロジェクトを開きます。
2. iOSデバイスまたはシミュレータでアプリをビルドして実行します。
3. 「ゲット」ボタンをタップして、周辺の避難施設を取得・表示します。
4. リスト内の施設をタップすると、地図アプリでその場所が開きます。
5. 「クリア」ボタンをタップすると、保存されたデータが削除されます。

## データ / API
本アプリは、SPARQLエンドポイント `http://sparql.odp.jig.jp/data/sparql` を使用して、現在地周辺の避難施設情報を取得します。
